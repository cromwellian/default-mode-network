```text
Use Vivian's local DMN profile signals:

Do not make a fact map or dashboard.
Make new creative works from the overlaps:

Tone:
editorial, strange, literary, tactile, designed like a small zine or tasting menu.
It should feel like something Vivian might actually enjoy, not a profile summary.

Format:
single self-contained HTML file with embedded CSS and JavaScript.
No external assets. Local/private. Browser-openable.
```
